# FlowiseChatEmbed

[![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=flat-square&logo=typescript&logoColor=white)]()
[![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat-square&logo=javascript&logoColor=black)]()

[Flowise](https://github.com/FlowiseAI/Flowise) chatbot arayüzünü herhangi bir web sitesine gömmek için kullanılan `flowise-embed` kütüphanesinin yerel bir kopyası.

## Proje Hakkında

Bu repo, kişisel bir projede Flowise tabanlı bir chatbot'u web sitesine embed etmek amacıyla `FlowiseChatEmbed` kütüphanesinin kaynak kodunu barındırır. Asıl kod `FlowiseChatEmbed-main/` klasörü altındadır.

## Kullanılan Teknolojiler

- TypeScript / JavaScript
- Rollup (build)
- Tailwind CSS

## Kurulum ve Çalıştırma

```bash
git clone https://github.com/mrvbyrm/FlowiseChatEmbed.git
cd FlowiseChatEmbed/FlowiseChatEmbed-main
yarn install
yarn build
```

Geliştirme modu:

```bash
yarn dev
```
